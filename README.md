# Quire releases

Installers and the update feed for Quire, a quiet desktop PDF reader for Windows and Linux.

Download the latest version from [Releases](https://github.com/snkLm8/quire-releases/releases/latest):

- **Windows:** `Quire-Setup-<version>-x64.exe`
- **Linux:** `Quire-<version>-x86_64.AppImage` / `arm64`, or the `.deb`

The Windows installer and the AppImage update themselves; the portable exe and the `.deb` do not.

This repository holds release files only.
